# รัฐธรรมนูญแห่งราชอาณาจักรไทย พุทธศักราช 2560 มาตรา 28 และมาตรา 33 — ยืนยันแล้วโดยผู้เขียน (2026-11-02)

ที่มา: ข้อความที่ผู้เขียนวางและยืนยันว่าถูกต้อง (ไม่ได้ระบุแหล่งเฉพาะ) ผู้ช่วยเทียบกับ `sources/รัฐธรรมนูญแห่งราชอาณาจักรไทย.pdf` (ฉบับชำระของสำนักงานคณะกรรมการกฤษฎีกา พิมพ์ 2026-11-02) ตรงกันทุกตัวอักษร (547 ตัวอักษรเท่ากัน หลังตัดช่องว่างและปรับรูปสระอำ) **ผู้ใช้ยืนยัน แต่แหล่งที่เทียบเป็นฉบับชำระกฤษฎีกา ไม่ใช่ราชกิจจาฯ**

มาตรา ๒๘  บุคคลย่อมมีสิทธิและเสรีภาพในชีวิตและร่างกาย

การจับและการคุมขังบุคคลจะกระทำมิได้ เว้นแต่มีคำสั่งหรือหมายของศาลหรือมีเหตุอย่างอื่นตามที่กฎหมายบัญญัติ

การค้นตัวบุคคลหรือการกระทำใดอันกระทบกระเทือนต่อสิทธิหรือเสรีภาพในชีวิตหรือร่างกายจะกระทำมิได้ เว้นแต่มีเหตุตามที่กฎหมายบัญญัติ

การทรมาน ทารุณกรรม หรือการลงโทษด้วยวิธีการโหดร้ายหรือไร้มนุษยธรรมจะกระทำมิได้

มาตรา ๓๓  บุคคลย่อมมีเสรีภาพในเคหสถาน

การเข้าไปในเคหสถานโดยปราศจากความยินยอมของผู้ครอบครอง หรือการค้นเคหสถานหรือที่รโหฐานจะกระทำมิได้ เว้นแต่มีคำสั่งหรือหมายของศาลหรือมีเหตุอย่างอื่นตามที่กฎหมายบัญญัติ
