# ระเบียบ ป.ป.ช. ว่าด้วยการจับ ควบคุม ค้น และปล่อยชั่วคราว พ.ศ. 2565 ข้อ 25 — ยืนยันแล้วโดยผู้ใช้ (2026-11-14)

ที่มา: ผู้ใช้วางข้อความข้อ ๒๕ พร้อมระบุว่า "ยืนยันแล้ว ถูกต้องตามนี้" ผู้ช่วยเทียบกับสำเนาราชกิจจาฯ `sources/ระเบียบ ปปช. จับ  ควบคุม  ค้น  และปล่อยชั่วคราว 2565.pdf` (เล่ม ๑๓๙ ตอนที่ ๒๑ ก ๘ เมษายน ๒๕๖๕ หน้า ๒๙) ด้วยเครื่อง ตรงกัน ยกเว้นชั้นข้อความ PDF ที่อ่าน "ผู้บังคับบัญชา" เป็น "ผู้บงั คับบัญชา" (ความเพี้ยนของชั้นข้อความ) ผู้ช่วยเปิดภาพหน้า ๒๙ ดูแล้วต้นฉบับคือ "ผู้บังคับบัญชา" ตรงกับที่ผู้ใช้วาง

ข้อ ๒๕ ในการจับ ควบคุม หรือค้นให้ผู้มีอำนาจดำเนินการดังกล่าวจัดเตรียมแผนและขั้นตอนปฏิบัติการ หรือการดำเนินการอื่นใดที่เกี่ยวข้อง โดยให้ผู้บังคับบัญชาเป็นผู้พิจารณาตามความเหมาะสมกับสถานการณ์ เว้นแต่มีเหตุจำเป็นเร่งด่วนไม่อาจดำเนินการตามที่กำหนดได้ ให้ผู้มีอำนาจจับ ควบคุม หรือค้นพิจารณาดำเนินการไปก่อน แล้วรายงานให้ผู้บังคับบัญชาทราบโดยเร็ว
