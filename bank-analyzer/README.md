# โปรแกรมวิเคราะห์สเตรทเมนต์ธนาคาร

```bash
pip install pandas openpyxl pdfplumber
python3 analyze.py statement.csv -o report.xlsx --threshold 50000
```

- รับ CSV / XLSX / PDF (ต้องมีชั้นข้อความและตาราง; PDF สแกนต้อง OCR ก่อน)
- จับคอลัมน์อัตโนมัติ (ไทย/อังกฤษ) รองรับปี พ.ศ. และคอลัมน์ถอน/ฝากแยกหรือจำนวนเงินเดียว
- ผลเป็น Excel: รายการทั้งหมด, สรุป, รายเดือน, คู่รายการตามคำอธิบาย, รายการที่ควรตรวจ
- สัญญาณ: ยอดสูง, ยอดกลมพัน, เงินสดยอดสูง, ใกล้เกณฑ์หลายครั้ง (แตกยอด), เงินเข้าแล้วออกเร็ว, รายการซ้ำ, ยอดคงเหลือไม่ต่อเนื่อง
- ผลเป็นสัญญาณให้ตรวจต่อ ไม่ใช่ข้อสรุปว่ากระทำผิด
- `samples/sample_statement.csv` เป็นข้อมูลสมมติ ห้ามนำสเตรทเมนต์จริงเข้ารีโปนี้ (เป็น public)

## โครงโฟลเดอร์
- `analyze.py` โปรแกรมหลัก
- `tests/` ชุดทดสอบ (`pytest bank-analyzer/tests`)
- `samples/` ข้อมูลสมมติเท่านั้น
- `private/` ที่วางไฟล์จริงในเครื่อง ถูก .gitignore ไม่ถูก commit
- `requirements.txt`

## แนวทางปรับปรุงต่อ
- รองรับรูปแบบสเตรทเมนต์รายธนาคาร (parser เฉพาะ)
- แยกชื่อคู่โอนจากคำอธิบาย แล้ววิเคราะห์เครือข่ายบัญชี
- กราฟรายเดือน, เกณฑ์ปรับได้ผ่านไฟล์ config
