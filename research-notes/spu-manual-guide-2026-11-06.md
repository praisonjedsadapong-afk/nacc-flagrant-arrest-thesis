# สรุปคู่มือวิทยานิพนธ์/สารนิพนธ์ น.ม. ม.ศรีปทุม (ปรับปรุง 2562) สำหรับสารนิพนธ์นี้

ที่มา: `sources/คู่มือการทำเล่มวิทยานิพนธ์ สารนิพนธ์ SPU.pdf` (75 หน้า มีชั้นข้อความ อ่านเมื่อ 2026-11-06) เลขหน้าด้านล่างคือเลขหน้าไฟล์ PDF แผน ข = สารนิพนธ์ (หน้า 55–58)

## 1. ลักษณะสารนิพนธ์ (หน้า 55–56)
- ผลงานวิชาการที่แสดงความคิดริเริ่มของนักศึกษา ขอบข่ายและความลึกน้อยกว่าวิทยานิพนธ์ แต่เขียนวิธีเดียวกัน
- แนวทางวิจัยที่ยกไว้: สำรวจ (Survey), กรณีตัวอย่าง (Case Study), ทดสอบทฤษฎีที่ไม่ซับซ้อน, แก้ปัญหา (Problem Solving) ในงานอาชีพ
- ต้องเป็นเรื่องที่เป็น **ปัญหาทางนิติศาสตร์** (หน้า 21) ผู้อ่านที่ไม่ใช่นักกฎหมายต้องอ่านเข้าใจ (หน้า 21)

## 2. ลำดับส่วนประกอบ (หน้า 57–58) ของสารนิพนธ์
ปกนอก (สีเขียวเข้ม) → สันปก → ใบรองปก → ปกในไทย → ปกในอังกฤษ → ใบรับรองสารนิพนธ์ → บทคัดย่อไทย → (บทคัดย่ออังกฤษ ตามตัวอย่างหน้า 16) → กิตติกรรมประกาศ → สารบัญ → สารบัญตาราง (ถ้ามี) → สารบัญภาพประกอบ (ถ้ามี) → บทที่ 1–5 → บรรณานุกรม → ภาคผนวก → ประวัติผู้เขียน
- ใบรับรองสารนิพนธ์และการพิมพ์ใช้รูปแบบเดียวกับวิทยานิพนธ์ เปลี่ยนชื่อบทนิพนธ์ให้ตรงปก
- ส่งสอบ 5 เล่ม (หน้า 57) แก้ตามมติกรรมการสอบภายใน 60 วัน ส่งเล่มเข้าปก 5 เล่ม + บทคัดย่อไทย/อังกฤษ 5 ชุด + แผ่นบันทึกข้อมูลบทคัดย่อ 1 แผ่น

## 3. โครงบท (หน้า 20, 23–24, 58)
- **บทที่ 1 บทนำ:** 1.1 ความเป็นมาและความสำคัญของปัญหา; 1.2 วัตถุประสงค์; 1.3 สมมติฐาน; 1.4 ขอบเขต; 1.5 วิธีดำเนินการศึกษา; 1.6 ประโยชน์ที่คาดว่าจะได้รับ; 1.7 นิยามศัพท์ (ถ้ามี) (เล่มนี้ไม่มี 1.7 ตามที่เคยตัดออกแล้ว คู่มือบอกว่ามีหรือไม่มีก็ได้ หน้า 23)
  - 1.1: ภูมิหลัง ความจำเป็น ปัญหาวิจัย; ทุกย่อหน้าต้องมีจุดมุ่งหมาย ใช้ภาษาไทยและภาษากฎหมายที่ถูกต้อง
  - 1.2: ข้อ ๆ วัดผลได้ **หลีกเลี่ยงคำว่า "ศึกษา" "พิจารณา" "เพื่อทราบ"** ใช้ "เพื่อหา / เพื่อกำหนด / เพื่อเปรียบเทียบ / เพื่อทดสอบ" เรียงตามความสำคัญ
  - 1.3: คำตอบที่คาดไว้ ตรงกับปัญหา ชัดพอพิสูจน์ได้ ขอบเขตไม่กว้างไม่แคบ
  - 1.4: ระบุกฎหมายอะไร ฉบับไหน ต่างประเทศคือประเทศอะไร มีสัมภาษณ์หรือไม่
  - 1.5: วิจัยเอกสาร (Documentary Research) จากหนังสือ วารสาร ตัวบท บทความ คำพิพากษา คำวินิจฉัย ข้อหารือ แล้ววิเคราะห์เปรียบเทียบ
- **บทที่ 2:** วิวัฒนาการ แนวคิด ทฤษฎีทางกฎหมายที่เกี่ยวข้อง + ทบทวนวรรณกรรม (หน้า 23–24, 58)
- **บทที่ 3:** ศึกษาประเด็นปัญหา / ศึกษาเปรียบเทียบ (กฎหมายต่างประเทศ มักอยู่ส่วนกลางของงาน)
- **บทที่ 4:** วิเคราะห์ประเด็นปัญหาตามข้อมูลบทที่ 2–3 ให้ครบทุกประเด็นตามโจทย์
- **บทที่ 5:** บทสรุปและข้อเสนอแนะ (บทสรุปอาจไม่แบ่งหัวข้อย่อยก็ได้ หน้า 31)
- ตาราง: "ตารางที่ N ชื่อตาราง" มุมซ้ายบรรทัดแรก ตัวตารางห่างชื่อ 1.5 บรรทัด คำอธิบายใต้ตาราง อยู่หน้าเดียวกัน; ตารางต่อหน้าถัดไปใช้ "ตารางที่ N (ต่อ)" ไม่ใส่ชื่อ

## 5. การพิมพ์ (หน้า 28–32)
- A4 80 แกรม หน้าเดียว; **Angsana New 16 pt** ทั้งเล่ม
- บทที่/ชื่อบท **20 pt หนา** กลางหน้า เริ่มบทห่างขอบบน 2 นิ้ว เว้นระยะ 1.5 บรรทัด
- หัวข้อสำคัญ (1.1) ชิดซ้าย **18 pt หนา** ห่างบรรทัดบน 1.5 ช่วง; หัวข้อย่อย 16 pt หนา (ไม่เกิน 3 ระดับ) ย่อหน้า tab 0.6″, 0.8″, 1.0″
- เชิงอรรถ **14 pt**; บรรณานุกรม 16 pt
- ระยะบรรทัด 1 ช่วง (หัวข้อสำคัญ 1.5)
- ขอบ: บน/ซ้าย **1.5 นิ้ว** ล่าง/ขวา **1 นิ้ว**; หน้าแรกของแต่ละบท ขอบบน 2 นิ้ว
- เลขหน้า: ส่วนต้น (บทคัดย่อถึงสารบัญ) เลขโรมัน I II III; ส่วนเนื้อเรื่องเลขอารบิก มุมบนขวา ห่างขอบ 1 นิ้ว; หน้าแรกของแต่ละบท บรรณานุกรม และภาคผนวก **ไม่พิมพ์เลขแต่นับต่อเนื่อง**
- เครื่องหมาย: หลัง "." เว้น 2 ช่วงตัวอักษร; หลัง , : ; เว้น 1; คำย่อหลายอักษรไม่เว้น (รป.ม., ม.ป.ป.)
- ตัวเลขฎีกาใช้เลขไทย (หน้า 28)

## 6. การอ้างอิง (หน้า 33–54) หลักสูตรนี้ใช้ **เชิงอรรถ (Footnote)** + บรรณานุกรม
- บรรณานุกรมรวมทุกแหล่งที่ใช้ ทั้งที่อ้างตรงและที่เรียบเรียงจากหลายแนวคิด (หน้า 33)
- หนังสือ: `ผู้แต่ง. (ปี). ชื่อเรื่อง (พิมพ์ครั้งที่ N). เมือง: ผู้พิมพ์.` เชิงอรรถเติม `หน้า N` ท้าย บรรณานุกรมไม่มีหน้า; อ้างต่อกัน "เรื่องเดียวกัน, หน้า N"; มีเชิงอรรถอื่นคั่น "ผู้แต่ง. อ้างแล้วเชิงอรรถที่ N. หน้า N."; ต่างประเทศ Ibid / Supra
- วิทยานิพนธ์/สารนิพนธ์: `ผู้แต่ง. (ปี). ชื่อเรื่อง. สารนิพนธ์นิติศาสตรมหาบัณฑิต คณะ... มหาวิทยาลัย...` (เชิงอรรถ + หน้า)
- บทความวารสาร: `ผู้เขียน. (ปี). "ชื่อบทความ". ชื่อวารสาร, ปีที่(ฉบับ). หน้า N.`
- เว็บ: `... (ออนไลน์). เข้าถึงได้จาก: URL [ปี, วัน เดือน].` (ต่างประเทศ `(Online). Available: ... [ปี, เดือน วัน].`)
- **พ.ร.บ./กฎหมายไทย (เชิงอรรถ):** `ชื่อเต็ม (ปี). (ซึ่งต่อไปจะเรียกว่า "ชื่อย่อ") มาตรา N วรรค N.` อ้างซ้ำใช้ชื่อย่อ + มาตรา **ไม่ใช้ "อ้างแล้วเชิงอรรถที่"** (หน้า 48)
- กฎหมายต่างประเทศ: `ชื่อเต็ม. (วัน/เดือน/ปี). มาตรา (ย่อ). (ชื่อประเทศย่อ).` (สหรัฐไม่ต้องใส่ชื่อประเทศย่อ)
- สนธิสัญญา/อนุสัญญา: `ชื่อเต็ม. วัน/เดือน/ปี. มาตรา (ย่อ). [hereinafter "ชื่อย่อ"]` อ้างซ้ำ `Id.` / `Ibid.`
- เปรียบเทียบมาตรา: `เปรียบเทียบ ชื่อกฎหมาย. มาตรา. กับ ชื่อกฎหมาย. มาตรา.` (อังกฤษ See Compare ... with ...)
- ฎีกา: `คำพิพากษาศาลฎีกาที่ 4548/2536 (เนติ.). ตอน 10 หน้า 1155.` หรือ `(ศาลยุติธรรม.). เล่ม 3 หน้า 15.` ฎีกาที่ไม่ตีพิมพ์: ระบุว่าจากตำราเล่มใด หรือคัดสำเนาไว้ในภาคผนวก; ออนไลน์ `ศาลฎีกา. คำพิพากษาศาลฎีกาที่ N/ปี. (ออนไลน์). เข้าถึงได้จาก: ... [ปี, วัน เดือน]`
- คำพิพากษาต่างประเทศ: `ชื่อคดี. หมายเลขคดี. (ปี).`
- เอกสาร UN/องค์กรระหว่างประเทศ: `ชื่อเอกสาร. ประชุมครั้งที่. หมายเลขเอกสาร. (ปี).`

## 7. บรรณานุกรม (หน้า 51)
- หมวดกฎหมาย: **เรียงตามลำดับศักดิ์ของกฎหมาย** (รัฐธรรมนูญ → ประมวลกฎหมาย → พ.ร.บ. → ... ) ในหมวดเดียวกันเรียงตัวอักษร; แล้วจึงคำพิพากษา/คำวินิจฉัย; กฎหมายต่างประเทศแยกต่างหาก
- หมวดอื่น: หนังสือ วิทยานิพนธ์ บทความ รายงานวิจัย เอกสารอื่น เอกสารต่างประเทศ ฐานข้อมูลออนไลน์ เรียงตัวอักษร
- บรรณานุกรมไม่ใส่เลขหน้าอ้างอิง
